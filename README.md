# Chufeng Deng · Academic Homepage

Personal academic homepage of Chufeng Deng, Huazhong University of Science and Technology.

Live website: https://cold-creator.github.io/

English is the default language; the language button switches to Chinese.

This repository contains a static website served by GitHub Pages from the main branch and repository root. No build tools or dependencies are required.

## Updating the website

- English content: index.html
- Chinese translations: translations.js
- Visual design and responsive layout: style.css
- Language preference and navigation: app.js
- Images: portrait.jpg and emi-platform.jpg

Upload modified files to main. GitHub Pages publishes them automatically.
